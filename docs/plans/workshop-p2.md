## 执行顺序

### 1. NEXT — #20 增加作者估算长度字段

目标：允许创作者自行填写内容大约会产生多少文字。

建议字段：

```text
作者估算长度
```

示例：

```text
约 800–1500 字
约 2k，视 EJS 循环次数而定
动态
不确定
```

实现原则：

- 可选自由文本；
- 明确标注为「作者估算」，不是系统统计；
- 不做 token / 字数预测引擎；
- EJS 循环、条件、动态内容使最终渲染长度无法可靠预测；
- create / edit / detail / admin review 均可读写/展示；
- 使用合理的小型文本长度限制；
- staging 人工验收后再 promotion production。

为什么先做：独立、小范围、低迁移风险，不依赖分类规则决策。
